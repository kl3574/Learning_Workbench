# Group native development evidence

The original `02-native-role-selector` artifacts are retained byte for byte. In its `group-lesson-actual.json`, fields named `declined` and `approved` contain the original **pending preview ACKs**, both revision 1. Those fields are not decision ACKs or decision readbacks. The first test did observe the decline HTTP 200 with no Job, and approval HTTP 202 followed by an actual runtime result, but did not preserve both complete decision ACKs. The old field names must not be used to claim that evidence.

The later `07-native-decision-receipts` lesson-only run uses explicit `first_preview_ack` and `second_preview_ack` names and preserves separately the complete `decline_ack`, actual `decline_readback` GET, and complete `approve_ack`. Its new assertions check exact id, revision 2, operation hash, decision and Job binding. The actual numeric result retains its original environment outcome; BLOCKED does not establish successful arithmetic.

The original lesson/practice run and original two single-block regressions remain in folders 02 and 03. The initial two failing selectors remain in folder 01. The correction changes only the new group native case; original native cases, runtime lifecycle, timeout configuration, and tracked screenshots remain unchanged. All screenshots use fresh cache output directories.

Receipts inventory a bounded declared source scope, not the whole worktree or installed runtime binaries. Synthetic loopback fixture traffic is not a vendor-model qualification. Session cookies, CSRF tokens, bootstrap secrets, runtime databases and browser profiles are excluded from this cache.
