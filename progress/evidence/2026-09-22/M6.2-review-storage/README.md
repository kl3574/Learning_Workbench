Raw files stay private. Public transforms are the five ordered, parameterized HOME/CI HOME/pytest-root substitutions in verify.py. There are no credential-value substitutions or scan exemptions. Raw and public byte counts/SHA256s, every transform count and aggregate binding are in manifest.json. Deduplication uses identical raw bytes; multiple aliases may resolve to one public file. Original .patch/.diff content is stored as .patch.log/.diff.log so readers can distinguish retained source diffs from instructions to apply them. Original manifests contain raw hashes and are read through this alias mapping.

Verify public bytes with `python3 verify.py`. To replay private originals, supply `--raw-base CACHE_ROOT --raw-home ORIGINAL_HOME --ci-home ORIGINAL_CI_HOME`; the originals must exist at the cache/path aliases in manifest.json. Verification never runs pytest, archived runners, SQL migrations or Git modifications.
