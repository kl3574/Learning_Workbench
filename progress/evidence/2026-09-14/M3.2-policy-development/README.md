# M3.2 Content 与 Policy 开发证据

本包记录局部开发验证，不是完整 M3.2 验收，也不替代后续整分支固定提交门禁。

最后联合命令真实结果为 **54 PASS，2 项已存在依赖弃用警告，14.01 秒**：19 项专属 Policy/Content/PracticeHistory 检查，24 项既有 Practice 检查及 11 项 Learning 检查。ruff 与 8 个生产模块的 mypy 检查通过。最终源码副本以 `.txt` 保存，不作为生产测试收集。

保留全部已有红/绿日志。首次 35 项初始化错误来自并行开发迁移使用 SQLite 不支持的 `ADD COLUMN ... UNIQUE`，后端修为独立索引；第一轮专属测试的一个错误是故障注入用了错误的触发器名称。之后两次真实自审缺陷分别为过严时间相等判断造成无关题历史 unknown，以及旧取消回执在后来保护状态下返回私有预览 warnings。修复后保留允许取消的行为，受保护回执不再提供私有 diagnostics。两次自审修前源码仅留哈希，未声称保存完整旧源码。

原始测试、模块和样例来自本仓库原创合成数学材料及真实本地 SQLite/import worker。未把未审题标成已审核、未执行评分、未调用学科模型。原先合法读到的内容不可能由服务端从用户浏览器或下载文件中抹除。待评分独立作答保护相关答案及无法证明安全的作者私有原件；正常安全正文恢复可读。

原件 `/tmp` 日志保持不变。公开日志仅替换个人目录、临时私有目录、运行时地址以及出现时的秘密值；manifest 分列原 SHA256 与公开派生 SHA256。receipt 中 raw_logs 的哈希仍指原始日志，公开文件使用 manifest 的 published_sha256。全部输入是合成测试数据，无真实学习资料、数据库、浏览器配置、DOM 快照或 capability 值。
