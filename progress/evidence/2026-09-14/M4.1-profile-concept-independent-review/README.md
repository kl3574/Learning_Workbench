# Bounded independent M4.1 review evidence

Original synthetic repository fixtures and controlled SQLite records only. Source lists, executed probes, exact outcome counts and before/after source hashes are retained in the receipts. Earlier failures remain separate from later passes. A raw artifact hash binds each public derivative to its retained private original; private paths and pytest fixture runtime representations are the only transformations listed in the manifest. No test assertion, pass/fail diagnostic, source logic or reported outcome is changed. No DB, browser profile, external provider, real learner record or captured credential is included.

The reviews are bounded and do not establish full milestone acceptance or expert mathematical review. Where a receipt records only early source hashes without original source bytes, this package does not invent a prior-source snapshot. Relative probe commands may require PYTHONPATH=. and -c pyproject.toml when run from the repository.
