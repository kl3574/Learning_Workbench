# M4.1 frontend independent development review

This package preserves bounded independent review evidence, including the failures that led to repairs. It is not the final M4.1 acceptance gate. Source hashes, test hashes, execution counts and the historical review boundaries remain separate.

The original two unchanged probes then passed together on intermediate useProfile `d3940a67…` (exit 0, 846 ms). See `profile/receipt.json` and its recorded source hashes.

The owner-native log is retained as evidence read by the reviewer: its four cases and 17.8 s duration are not added to the reviewer's test count. Shell/count fixes were not dynamically tested by the two Profile hooks. Initial Profile source text was not copied; the initial exact source SHA values and logs are retained, and no historical source snapshot is invented here.

## Runtime and public provenance

The independent tests use React, the actual application DraftStore implementation, fake-indexeddb transaction storage, and controlled typed transport/ProfilePort responses. They do not establish native browser disk persistence, live API authorization/CAS/idempotency, full frontend workflow acceptance, CI completion, or overall M4.1 completion. No reviewer production changes, default-port servers, or Git mutations were made. All test content is synthetic and authored for this project: fixed workspace labels, original route goals, generated command UUIDs, and artificial content hashes. No database, browser profile, cookie, token, session snapshot or private learning material is included.

The historical `profile/pending-findings.json` preserves its then-pending state and is superseded by later receipts. Current-source snapshots are explicitly named `*.final.*.txt`; they are not substituted for initial source bytes.

Scripts and TypeScript source are archived as `.ts.txt`/`.tsx.txt` so they are not collected as production tests. Personal checkout paths are replaced with `<repository>`. Known temporary artifact references become package-root relative paths; complete React DOM blocks and ANSI formatting are removed from logs. Errors, assertion differences, stacks and run counts remain. Imported JSON records include a notice: their embedded hashes preserve ORIGINAL recorded bytes even when artifact references now name the public derivative. Only `manifest.json` entries named `published_sha256` identify package bytes. `raw_sha256` identifies untouched local originals. No derivative hash is represented as an original hash. Replaying archived scripts requires restoring extensions and paths in an isolated temporary test environment; packaged scripts were not rerun after transformation.

The package scanner checks actual proposed repository-relative paths. Manual review additionally inspected the scripts, synthetic provenance, log extraction boundaries and each payload for credentials/DOM/runtime data. This bounded inspection is not a guarantee for arbitrary content.
