This package preserves five already executed local runs. It does not establish the cause of either original 3dd75f0 GitHub browser failure and does not mark that CI repaired or passed. No tests, browser, services, network calls or repository changes were performed by the packager.

The boundary log records 1.6599019999999953 ms for unavailable-page, 250.441177 ms for never-completes and 2.359899999999982 ms for unwritable-target. Its helper hash is a post-run readback only; no separate pre-run hash was captured. The preserved receipt says this explicitly. The 250 ms timers bound observer waiting under normal event-loop scheduling, not hard real-time execution or guaranteed cancellation of all underlying I/O.

Stored source receipts for diagnosis-02 contain equal before/after maps of 783 files; observer-native-01 and observer-fault-01 each contain equal maps of 784 files. The packager compared each map with its separate source-before.json and verified recorded log/helper/probe/diagnostic hashes where provided. These are the actual owner receipts, not new runs or a reconstruction of the full source tree. Different run groups have different declared source inputs. Private harnesses/configurations and the one archived helper are included as .txt; no source tree is copied. The initial failed harness has no after-run product source receipt.

Both PNG files were actually viewed before publication. The diagnosis-02 image shows the passing original case's final deliberately mismatched-link warning. The fault image shows the synthetic nativehistory r2 object unavailable with Failed to fetch; the Agent says no model is configured. Only synthetic fixture and application UI content was visible, with no user content or credential. Images are included byte-identically. The fault diagnostic records 41 observed GET events, zero omissions, an ERR_INTERNET_DISCONNECTED event and post-failure reader_count=0. It is not an original CI screenshot or failure-time DOM snapshot.

All original files remain private and unchanged. Each manifest entry maps the public path to its original path relative to the acceptance cache and records raw/public SHA-256 and byte counts. Text derivatives apply only fixed literal home-prefix replacements (the private-home-prefix to `<private-home>` and the GitHub-runner-home-prefix to `<github-runner-home>`); no failure lines, assertions, warnings or ANSI escapes are removed. Harness/config archive suffixes are declared separately from byte transformations. The authored README and readback have no pre-existing raw-run source.

The aggregate is SHA-256 of UTF-8 json.dumps(path-sorted [{path,sha256:public_sha256,size:public_bytes}], sort_keys=True, ensure_ascii=False, separators=(",", ":")); manifest.json is excluded. Every candidate file, including the manifest, is inspected with the unchanged repository publication inspector at its proposed progress/evidence path, plus a bounded runtime-identity/credential scan. The packager does not claim pattern scanning can detect every possible secret. Independent static review remains in its separate m52-reader-diagnostics-independent-review-v2 package.
