# Independent Authoring generation review and bounded repaired recheck

This package preserves four original real SQLite/synthetic loopback counterexamples and their independent repaired recheck. It is a cache-only publication candidate, not a whole-stage acceptance or hosted model result. No product source, original assertion, old failure or progress file was changed by the reviewer.

Original executions: probe-red-01 has 2 FAIL (1.30 s); probe-red-02 has 2 FAIL (1.35 s). They demonstrated self-consistent candidate replacement accepted despite unchanged Provider/Jobs origins; revoked unused consent failing the same Job instead of allowing a fresh explicit preview; mutable execution actor borrowing another current author after grant-time author demotion; and restored-author read rejecting a valid control-only terminal.

Repaired executions: original-four-01 runs the exact same four private probe bytes and has 4 PASS plus 2 dependency deprecation warnings (1.69 s). permanent-six-02 has 6 PASS plus the same 2 dependency deprecation warnings (3.84 s): four permanent counterparts and two HTTP tests. These are overlapping scenarios, not ten distinct business cases. All 33 explicitly recorded inputs stayed byte-identical before and after both recheck runs; this bounded list is not a complete dependency inventory of the host or all imported modules.

The initial review.md contained an inaccurate repair recommendation that could be read as treating the original Provider grant actor as session identity. The preserved actor-correction-addendum.json is authoritative on that point: old Provider command.actor/fingerprint.actor are workspace_id and do not record the original granting session. The new fix adds an Authoring-owned callback authorization fact with actual identity.id; it does not redefine the old Provider ledger. The historical executed probe and its permanent counterpart retain the old ambiguous inline comment; raw bytes are preserved, and the correction applies to those comments too. The original corruption observation remains valid.

The four original failure assertions now close within this scope. Candidate parsing and terminal-result bindings are checked together; unused revoked/expired consent returns to approval only after proving no dispatch began; the current actor is checked against the new owner authorization fact; restored authority projects checked original output without creating a candidate, upgrading status or sending another request. The revoke probe ends at a fresh explicit preview, not a second grant/dispatch. The numeric HTTP test accepts actual environment_unavailable/BLOCKED as a truthful environmental result; it does not establish successful isolated arithmetic. Numeric sandbox execution remains BLOCKED_ENVIRONMENT.

The package contains original executed probes and drivers, original failure logs/receipts and actual input inventories, the correction, repaired logs/receipts and actual inventories, the three exact permanent test files, and the reviewed migration. A compact four-source unified diff and before/after bindings replace duplication of all 33 reviewed sources. The source archive remains private and the product sources will be separately versioned by the owner. No binary/database/runtime payload or user credential is included.

Transformations are explicit per file in manifest.json: one fixed home-prefix replacement, and a targeted replacement of the synthetic test session CSRF value in pytest's shortened SessionIdentity repr. The actual sensitive value is not placed in the manifest or any marker; original raw files remain unchanged privately. All observed original CSRF values were checked for absence from every supplied public byte stream. Other synthetic IDs remain synthetic diagnostic facts. Raw hashes inside normalized receipts still reference original raw bytes; public hashes identify the derivatives actually supplied here.

The actual repository scripts.check_publication.inspect checks every supplied file under the proposed progress/evidence path. Its bounded scan supplements the provenance selection and exact-value absence check, and does not promise to detect arbitrary private text. No further tests, browser, model call or production edit occurred while creating this package.
