# 0033: Bind declared Draft create/edit routes to the actual editing owner

PRODUCT_DESIGN.md Appendix A rows 1262–1263 declare POST `/drafts` and PATCH `/drafts/{id}`. The registered handlers delegate to the new `authoring_edit` service and are protected by the existing current-session, Origin, CSRF, duplicate-header and private-response dependencies. POST requires one original Idempotency-Key. PATCH requires `expected_revision` and allows an optional original key, matching ADR 0032's permanent-command semantics. Unknown or repeated query parameters are rejected. An unsupported kind or base is a capability conflict with zero write; the public create DTO still expresses all declared kinds and nullable `base_ref`.

The existing GET `/drafts/{id}` remains the Import snapshot contract. No generic editing GET or editing publication route is inferred from these two write rows. The editing service exposes an internal exact-version read to Quality. An editor that must restore its own text after a page reload still needs an explicitly specified public read contract.

`DraftPatch.value` retains a recursive JSON value rather than narrowing the public field to a string. A named `DraftJsonValue` Pydantic alias produces an explicit recursive OpenAPI schema for null, boolean, integer, finite number, string, array and string-key object. The application whitelist then accepts only strict title and `body_markdown` strings for this first text-block slice. The TypeScript projector accepts a typed object map only when its values refer back to this named JSON type; bare or unrelated open maps remain rejected. Runtime semantic validation and size/depth limits remain in the owner DTO and service.

Contract generation runs from actual runtime OpenAPI and keeps the declared but still unregistered operations visible. The new route binding does not change PRODUCT_DESIGN.md, core domain models, old migrations, Import producer, private answers, Content current, or Review decisions. HTTP tests use actual SQLite/Import/Content/Review paths with synthetic publication decisions. Those decisions verify protocol wiring, not academic approval or all-kind editing support.
