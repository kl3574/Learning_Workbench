# ADR 0006 — 暂存、预览与原子确认导入

唯一规范为 `PRODUCT_DESIGN.md` 3.0.0，第 9、10、15、16、20.2 章及附录 A—C；本记录说明 M2.2 的实现选择。最终验证版本和结果以 `progress/` 回执为准。

## 导入事务和权限

`POST /imports` 接收真实 multipart 文件，以原始字节计算哈希，先完成 blob 持久化，再在一个 SQLite 事务中写入 source、import、job 和 outbox。202 只表示暂存成功。解析在独立子进程运行；worker 通过数据库 revision、租约所有者和租约期限校验领取资格，超时或取消后终止解析进程。到达预览阶段只产生候选草稿，没有正式课程或学习事件。

确认显式绑定原件哈希、警告代码和 ID 映射。导入终态、正式修订、当前指针、依赖事件、私有解答和迁移回执由同一数据库事务提交。append 在暂存时冻结目标课程的精确引用，确认时若当前版本变化则冲突，不覆盖已存在对象。ID 映射重算依赖哈希，并保留同一对象的多次修订；候选 Note 的工作区变更和精确锚点状态进入回执。

所有相关 HTTP 操作、原件下载以及 worker 产生副作用前都检查工作区活动独立测试；切换 author 不绕过此策略。学习包在未验证前作为私有原件保存。完整归档结构与 manifest 检查后，只有完整的 learner 包可成为学习者可下载的原件；拼接、前缀、尾部或未声明内容不得借解析器只读取其中一部分而被公开。作者包解答只进入服务端私有库，包内审核声明不被直接采信。

## 保真和候选内容

MD 保留公式、代码、标题和引用链接；拆分后的块包含自己所需的引用定义，能够独立渲染。TXT 保持一个未结构化文字块；HTML 清除主动资源，保留明确提供的 TeX，并显示降级警告。LF/BOM 等候选转换不改变原件。正文来源使用原件哈希和定位信息，未执行的数学或来源审校保持 NOT_RUN。

无效 UTF-8 按第 20.3 节进入显式编码选择预览。现有 multipart 契约不包含编码参数，因此原始任务保持失败，原件保持原字节。浏览器仅在内存中保留用户选择的 File；用户选择编码后以严格解码器预览普通文本，确认后可另行下载明确命名的 UTF-8 派生文件，再作为新输入导入。重新打开窗口时必须重新选择并核对原件哈希，不能声称从任务 ID 恢复了浏览器 File。派生文件有自己的新哈希；不会替换原件、自动上传或自动确认原失败任务。此流程提供编码选择能力，不增加未列明的 API 字段，也不宣称服务端已建立原件到派生文件的内容审校关系。

learnpack 的符号、引用、被动资源和未可信质量回执均保留并绑定导入。未知或主动资源类型显式拒绝，不能丢弃后宣称完整导入。PDF/DOCX 在 M2.2 返回明确的待实现失败状态，提取实现和验收属于 M2.3。Reader 接入正式课程及笔记 CRUD 属于 M2.4。

## 可配置预算与默认契约

第 10.1 节明确允许扩大安全预算。五项配置为 `LEARNING_MAX_UPLOAD_BYTES`、`LEARNING_MAX_BLOCK_CHARACTERS`、`LEARNING_MAX_PACKAGE_BYTES`、`LEARNING_MAX_PACKAGE_FILES`、`LEARNING_MAX_COMPRESSION_RATIO`，默认分别为 50 MiB、400,000 字符、200 MiB、2,000 文件、100。它们必须是正整数，解析不得截断后宣称完整成功。每次暂存冻结实际预算；重启或改变环境配置不改变已有任务的预算。

附录 B 的 Manifest/FileEntry 同时包含默认文件数和文件字节上限。规范原文、提取出的领域模型和默认生成契约保持原样；本地解析器针对显式配置派生 Manifest/FileEntry，仅替换这两个资源预算字段，继续执行原来的严格字段、路径、重复、根课程和可见性校验。其他字段语义，包括元数据 Text 的长度约束，不随资源预算放宽。这是落实正文明确配置能力的运行时适配。

## 实际前端和契约投影

导入窗口使用实际生成的九个 API 操作；上传通过 FormData 保留原始 Blob 字节，由浏览器生成 multipart boundary。确认界面显示候选内容、警告、明确 ID 映射和发布结果。恢复缓存只保存工作区与服务端返回的 import/job 标识；刷新时从 API 回读状态。原件下载前核对实际字节数与 SHA-256，下载地址仅为当前同源受控端点。

角色变化使既有候选投影和异步读取失效，避免旧权限响应重新进入界面。取消后不产生正式课程。浏览器截图仅使用合成输入；原始失败、修复说明与最终测试分别留证，测试通过不代表数学内容已审校或后续学习闭环已验收。
