# 0010 — 测验快照、策略与未评分作答

状态：M3.2 实施决定；实际验收以 progress/state.json 及对应源提交回执为准。唯一规范 PRODUCT_DESIGN.md 3.0.0，SHA-256 `ab061119163b5b2a10411bb90d7cae45bf2e2b14082f4e9266f6c9452db3870c`；正文 §6.4、§7、§13、§19.2、§20.2 与附录 A/B/C/E 共同约束。本 ADR 只具体化工程接缝，不替代规范。

创建测验时固定 assessment 完整引用、按顺序分配的公开题目完整引用、私有 solution_revision/hash、策略及创建时间。正常恢复和评分均不得解析“最新答案”。首次交卷将最后已经保存的作答、时间、原因、提交事件与评分请求 outbox 同事务持久化；重复同键请求不产生第二份副作用，当前权限检查先于回执回放。工作区是首期单用户版本的稳定所有权边界，浏览器重新 bootstrap 不导致丢失测验。

四项写操作的回执绑定到当前幂等记录实例、原请求哈希、实际 attempt、冻结分配哈希和完整结果哈希，不能从缓存正文的 id 推导授权对象。回放先校验绑定和当前策略，再与真实冻结公开投影核对；保留原回执的历史修订与状态，不伪装成新一次写入。幂等记录到期删除时通过外键一并删除回执绑定，使重用键对应新实例；持久化最后一项回执失败也回滚同事务全部业务副作用。数据库故障注入发现并修复过三项缓存损坏检查缺陷，该测试不声称普通 HTTP 用户具有任意改库能力。

M3.2 注册七项实际接口：列表、创建、详情、GET 作答、PUT 作答、交卷、放弃。核心 AttemptPublic 没有作答字段，GET responses 单独读取；从未保存时 saved_at 为 null。安全预览与冻结参考状态可通过严格应用 DTO 扩展，不改变附录 B 的 54 项核心模型。结果/重评路由接续真实评分器后实现，不以空结果填覆盖率。

## 参考作答与审核

规范限制未经正常审核的内容用于真实学习者评分，以及独立证据的资格；它没有规定 AttemptCreate 必须拥有 approved 字段。这里允许完整性有效但状态为 draft/needs_review 的冻结答案支持明确标注“未审、未评分”的参考作答。缺少私有绑定和坏哈希拒绝开始，不猜答案，不把导入确认冒充数学审核。之后即使发布 approved 新修订，旧测验仍使用旧绑定，其未审资格不会自动消失。

M3.2 没有评分器；交卷保持 submitted，表示作答与评分请求已经持久化。不会创建没有消费者的虚假评分 Job，也不会返回假成绩、评分百分比或独立能力证据。M3.3 接通评分时还必须测试 outbox 消费和任务一次性；本阶段的一个 outbox 不代表已执行一次评分任务。

## 模式与答案生命周期

independent 固定为操作帮助、无模型、无联网、阻断教材笔记。open_book 允许已授权材料，但只有操作帮助且不联网。assisted 允许已有授权范围内的学科能力；能力不代替用户外发/联网授权。本阶段未配置真实 Provider，allow_web 不凭模式自动授予。

活动独立测验的工作区只能访问该次题目和作答，不能通过旧练习、其他测验、作者角色、导入私件、下载或幂等旧回执绕过。允许同一创建命令回放自己的活动测验；另一个独立测验活动时不能回放旧题面。开始前，在同一排他事务检查真实 queued/running/awaiting_approval 学科任务；cancel_requested 或过期 lease 不等于任务已经停止。未实现的 Provider/RAG/Codex 接口不计作真实跨层防护验收。

交卷解除“正在作答”的普通材料锁，并不等于 independent 已完成必要评分。与待评测验相同题目/暴露组的私解、旧解答回执和无法证明不含答案的敏感附件继续执行答案释放检查。不能因一张待复核试卷锁死所有无关教材；无法安全分离内容的作者私件允许保守拒绝，并返回明确原因。M3.2 尚无可证明必要评分已完成的情况，M3.3/M3.4 再定义实际释放条件。open_book 和 assisted 的标准答案也遵守冻结 policy.solution_release，不因换到 Practice 标签提前释放。

放弃仅从 active 转换，保留参与事实而不产生零分或提交事件。浏览器关闭不隐式交卷。M3.2 先实现无时限，带 time_limit_seconds 的蓝图显示实际时限但明确尚不可开始；不静默忽略或显示无效倒计时。

## 课程反向关联与已见事实

核心蓝图没有 course_ref；`assessment-course-association-v1` 是本阶段的工程细化：读取每道已发布 Question 的固定概念依赖，校验 Concept 的准确修订/hash；只有某一个完整历史 Course.concept_refs 包含本蓝图所有准确概念引用时，才返回该 course_id 下的测验及见证 course_ref。不同课程可共享一个测验，多个历史版本不能拼成从未存在的范围，不沿先修依赖扩张，不用题目 ID、标题、包名或当前指针猜归属。未关联蓝图仍可从工作区范围列表访问。

prior_seen 由 Practice 自有分配/帮助端口和 Assessment 自有历史分配合并，按 exposure_group 跨题目修订考虑。创建后即获得题面分配、随后放弃的记录属于保守的“曾分配/曾见”，不声称浏览器实际阅读或形成理解。损坏/无法证明的历史为 unknown，不能当作首次未见。事件表的一次 test_submitted 不被复制成每题多个假事件；本阶段不生成 grade_finalized 或独立证据。

## 模块端口与验收范围

工作台布局、标签引用和本次作答恢复不属于教材正文访问。独立测试期间，Workbench GET/PUT 只返回去除全部 selection 的安全投影；保存布局时保留服务端同一标签、同一准确上下文的原选文，投影读取本身不写数据库。核心 WorkbenchSession 不增加字段，HTTP ETag 绑定工作区、修订和当前独立测试；客户端保存时携带原读取或本机候选的 If-Match。进入独立测试允许同修订的完整投影添加本次标签；退出或换到另一测试后，旧脱敏投影保存返回 412，不把 null 当作用户删除选文。缺少 token 且可能清除原选文的旧客户端也须重新读取比较。显式三方选择保留本地布局时，未触碰的脱敏选文从最新完整服务端版本保留；不能在发送时偷偷把旧候选 token 换成最新 token。

恢复布局或明确采用服务端会话时，将该选择绑定到点击时的编辑版本及恢复操作；等待读取期间的新编辑不能被旧选择覆盖。作答草稿同样保留仍运行页面各自的未同步分支：另一页面选择候选之后，活跃编辑页面可以重新保留自己的候选。要验证最终单一选择，应先确认其他编辑页面的候选已安全持久化并明确关闭；不能为消除冲突提示删除其他页面的未同步作答。

Assessment 写自己的 attempts/responses，Content 提供准确题目与私有冻结绑定，Policy 通过 Assessment 自有只读端口判断权限；Practice 提供自己的历史，Jobs 提供实际任务状态，Learning 以可信事务端口写入一次 test_submitted。各模块不直接读写别人的 ORM 表。

验证需覆盖实际 SQLite/HTTP 的 CAS 和终态竞态、权限变化后的幂等回放、active/pending 的私解保护、课程历史见证、未审状态回读、任务与开始互斥、重启后本机候选恢复。实际命令、失败/修复、源哈希和截图另存进度证据；本 ADR 的存在不代表这些检查已经通过。
