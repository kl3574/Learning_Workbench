# 问答任务、上下文与实际帮助

依据唯一 PRODUCT_DESIGN.md 3.0.4 的第12、20章及附录A/D。本文记录实现选择，不构成另一份产品规范。

原有问题草稿只能保留文字，无法建立真实任务或恢复模型结果。本阶段把 Thread、Run 和 Jobs 绑定到持久记录：一次明确提问创建一个真实 tutor Job、用户消息和原命令回执；后台准备 Context 后等待批准。Provider 的预览和批准分别绑定同一任务及不可变输入，浏览器不提供虚构 consent 或历史消息。回放先核当前权限和完整原会话，再返回原 ACK；当前状态另读 GET。

Context 通过 Content、Practice、Assessment 所属端口读取准确修订。课程导航链不自动成为附加权限。练习和测评使用真实会话、题目及已保存作答，复盘只纳入已获现有规则允许的反馈。当前块不会自动提升为父小节。字符预算包含系统、本轮问题、至多四条真实历史及完整引用包装；必需交互单位超限会拒绝，可选材料只能整块省略。完整输入证明继续由 Provider 独立准入，12,000字符不是 token 证明。

Tutor 消费 Provider 已核验的原 answer/refusal 产物及终态，不从投影的 finished 猜测回答成功。服务器持久事件形成连续 SSE，连接中逐次核当前身份和学科权限。最终消息、Run、计量关联及 Jobs 终态在同一事务提交；取消保留既有部分输出和真实远端事实。重启可以读原 Provider 终态完成本机提交，不重新派发。坏会话拒绝准入，调度不会将坏记录伪修复成正常失败结果。

首次持久化的实际非空白练习回答同时触发 Practice 自有 model 帮助事实和暴露记录。它不推进作答 revision、不改变本轮冻结输入，也不伪称规则提示或标准解答。当前会话可显示提交后新增帮助，原提交快照和 ACK 仍只反映当时的事件集合。GET、SSE重连、纯拒答和未外发任务不会补写帮助。

客户端先将不可变命令与 key 存入 IndexedDB，再发送。会话、工作区、对象和运行序号共同限制异步响应交付；切页不会把旧回答放进新上下文。事件解码严格检查分帧、类型、任务与连续序号，终态须另读服务器快照。实际输入材料与未经核验的模型输出分开展示，未执行外部搜索时不生成引用结论。

测试专属工厂使用有完整字节计量规则的本机 HTTP 协议，其模型、proof、秘密及运行数据不进入生产注册表。生产 Tutor 来源已接入；完整生产模型证明仍未注册。独立 DeepSeek 15-token 冒烟、受控完整链、原生浏览器和固定源码整阶段门禁分别记录在 progress；任一项不能替代平台真实模型或教学质量验收。
