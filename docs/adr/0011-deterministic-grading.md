# M3.3 确定性评分与人工复核

依据仅为 PRODUCT_DESIGN.md §13.1、§15.1、§20.2 和附录 HTTP/core 模型。此记录解释实现取舍，不替代规范。阶段验收以 progress/state.json 和绑定源码的测试回执为准。

## 判分与审核状态

纯规则端口读取服务端冻结的完整题目引用、私有答案修订及哈希、原提交答复，重新验证所有类型与绑定。错误引用属于完整性错误，不记为学生零分。正常导入的私有答案保持 needs_review；后来的 approved 新修订不改变已开始会话的 pin。规则测试中明确假设 approved 的原创合成输入只验证该条件下的算法，不是内容审核工作流或实际人类数学审批。

`deterministic-v1` 固定选项 ID 精确比较、文本 NFC 与首尾 Unicode 空白去除（区分大小写，保留内部空格，同义词仅来自允许集合）、有限十进制数与显式单位表。容差使用 `abs(user-expected) <= atol + rtol*abs(expected)`，转换到同一基本单位后比较；不执行 Python、算式或符号代码。支持单位表和资源上限由 grading_rules.py 版本化，未知单位或越界输入明确需复核。裸数依据题目公开输入说明使用目标单位；不从私有审计泄露目标值。

已审客观题的空答可按明确规则记零；解析失败、未审答案、符号或 rubric 人工判定保留 score=null。`numeric_tolerance` 的计算题只判最终数值，明确提示步骤未评分，原步骤始终保留。评分修订 `grading_revision` 使用核心模型规定的正整数；具体算法版本保存在 `grading_rules_version`，不能用二者替代彼此。

## 持久化与真实任务

Practice 的评分与原提交、原生 practice_submitted 事件、outbox、私有审计及幂等回执同一事务。M3.1 已存在的 StoredSubmission 没有新增默认字段，旧 canonical 字节及哈希保持不变。新增的私有审计表通过提交哈希和 outbox 绑定；读回会检查这些关联。旧未评分记录保持原状，不在 GET 时重新计算。

Assessment 提交同事务保存真实评分 Job，原评分 outbox 和提交事件必须通过完整性验证；历史 M3.2 提交通过已有持久状态恢复真实任务。现有单 Worker 调度导入与评分，评分使用租约及终态事务。过期领取与重投递不能产生第二份同修订评分；取消失去租约的工作不能发布结果。`GET result` 在任务尚未完成时返回严格应用类型 AssessmentGradingJob（202）：实际 JobRef 与必填 last_completed_result（最近真实完成的评分或 null）。失败、取消和未终结任务保持真实状态；旧评分显式标作“上次已完成评分”。该历史基准不携带 solution_markdown 或 solution_reviews，仍先执行当前 attempt_read；新完成结果的 200 投影另外执行当前解答释放策略。失败或取消后可基于真实旧修订明确新建复核命令，未终结任务阻止重叠提交。ACK 回执刷新后不伪装为未提交草稿，也不自动重放。

损坏的评分任务逐条隔离为失败；没有可验证作业绑定的历史提交保留独立恢复诊断。单条坏记录不能阻挡其他合法评分或安全导入，也不能通过忙循环冒充工作进展。停止 Worker 时放弃本轮发布，让新 Worker 按租约规则恢复。隔离不表示已修复损坏的原始提交，也不为其生成分数。

人工复核需要当前数据库中有效的 author 会话、明确理由、逐题分数及依据、预期评分修订。服务端以私有工作区 HMAC 密钥签名完整操作，绑定会话身份、提交/分配哈希、时间和原评分修订。签名及原操作不可变，公开收据不含私有会话身份或密钥。此签名证明本地服务接受过该作者会话操作，不是外部认证身份、数字证书或数学正确性证明。重放返回原 Job，旧评分不覆盖；新增分数不能超过冻结题面上限。

## 公开边界与后续阶段

私有 trace 保存规则输入、规范化结果、十进制比较和固定 pin，仅在服务器内部审计表存储。普通 Practice 结果不会附带解答。Assessment 结果按当前服务端 Policy 释放解答，独立模式中需完成必要评分；释放后仍披露原参考内容的审核状态。角色或活动测试改变后，旧请求和已缓存私有投影不能绕过新策略。

前端区分任务状态、评分修订、作答修订与本机复核草稿；复核命令沿用自己的幂等身份。未确认保存、断网或版本冲突时保留本机候选，不以空分计算完整总分。签名人工分数不自动升级标准答案审批。M3.3 的 `eligibility_status=not_evaluated` 明确表示完整独立证据资格尚未计算；M3.4接续可信 grade_finalized、结果历史与证据闭环，不把普通分数提前写成已掌握。
