# ADR 0004 — M1 Workbench 会话、合成材料与本地草稿

日期：2026-09-14。唯一产品规范：根目录 `PRODUCT_DESIGN.md` 3.0.0，第 4、8、11、17 章与附录 A/B/F。本记录只说明实现细化，不增加产品需求。

React Shell 将导航、标签与布局、Reader、Tutor、对话框和会话持久化拆分。服务端 WorkbenchSession 是已确认 UI 会话的权威来源；React Query 保存读取缓存，PUT 以 expected_revision 做 CAS。目录滚动历史按工作区、课程与入口存为本地 UI 缓存；当前入口的 directory_scroll 仍由服务端会话确认，切换后恢复目标入口历史。待同步 UI 按工作区与浏览器页面独立保存；其他页面的候选快照只提供显式恢复入口，不静默替换。所有存储失败都显示未保存并保留当前页面内存，服务端确认前不显示成功。普通重连优先保留同工作区未确认内存及其基准；本地待同步信封同时保存候选与可用的原基准。服务端版本变化时显示三方可读比较，缺失基准标未知；明确采用本地版本后使用服务端 revision 做 CAS，明确采用服务端才替换本地布局。请求来自生成的 API client 和 DTO。首次启动只处理 fragment 的一次性 code，立即清除 fragment，后续通过 HttpOnly 会话读取 CSRF。错误与版本冲突可读，未确认 UI 变更按已确认 workspace_id 暂存，不能跨工作区提交。

标签身份严格由 view_kind、对象实体/ID、精确修订和 attempt mode 形成元组，再用 SHA-256 派生 68 字符 ID，避免合法 80 字符对象 ID 导致 SavedTab 越界。标题不参与身份；同名、不同修订与不同模式不合并。预览替换只发生在无草稿且未固定标签；关闭问题草稿提供保留、放弃、取消。侧栏宽度、折叠、展开集合与阅读滚动写入服务端会话。每标签的公式详情展开和稳定焦点目标保存在 workspace + tab 的本地 UI 缓存，等待懒加载正文就绪后恢复；抽屉存在时不抢焦点。继续浏览按 workspace + course + 教材入口保存精确最后阅读引用，不固定返回样例第二节。正式路线尚未实现时目录保持空态，不把章节改名充当 typed 路线任务。选文监听 selectionchange 与键盘 keyup，只接受在原始正文中唯一定位的引文；多匹配或无匹配明确提示且不附加猜测的 anchor。专注模式由两个折叠字段共同表示，避免增加另一套 HTTP 状态。抽屉使用原生 dialog 与显式 Tab 首尾约束，关闭返回触发者焦点。

未发送问题草稿按 workspace_id + tab identity 独立存入 IndexedDB。readwrite 事务同时执行 expected revision 检查与写入；冲突候选在同一事务保留，首次冲突无需刷新即可查看原基准、当前输入与已存文本；基准未知时明示，随后显式选择。BroadcastChannel 仅通知工作区标识，不传正文。无已确认工作区时只保留当前页面内存，不擅自归属另一工作区。存储失败显示未保存，dirty 文本不被刷新通知覆盖，并触发离开页面保护；不以本地草稿冒充服务端笔记、成绩或学习证据。

M1 的课程为明确独立加载的合成 UI fixture（8 章，每章 6 节）。每节包含独立正文与真实内容哈希，示例已读/过期状态只作为展示字段。首次工作区没有课程或成绩。Reader 必须完整匹配 entity/id/revision/sha256，否则展示引用待解析并保留原快照。上下文发送桥复制并递归冻结引用；M1 只以显式 synthetic executor 单测验证异步归属，不开放模型发送按钮，不冒充真实 Tutor 回答。

Markdown 通过 react-markdown 的 unified/remark AST 投影；不执行 MDX，不投影原始 HTML，不主动加载图像。MathJax 4.1.3 的 TeX base/ams 与本地 tex-font 输出 SVG；无 require/autoload/html 扩展，禁止动态宏和外部资源，公式超限或不支持时保留 LaTeX 并显示中文错误。Reader 按需加载数学模块，真正完成渲染后恢复滚动，防止加载占位元素把已存阅读位置压为零。

M1 测试只证明工作台行为与本地安全显示。正式内容导入、笔记、习题、测试、评分、真实 Provider、Codex 与学习效果仍属于后续阶段，未据本次结果验收。
