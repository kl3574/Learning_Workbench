# 本地 Codex 控制会话

唯一合同为 PRODUCT_DESIGN.md v3.0.14 §20.16。当前创作入口可以明确准备、批准或拒绝一次受限本地建会话操作，再读取实际状态。它只建立核验过的 thread 映射；不会生成教材或发起模型、turn、工具、网络请求，三个产品 capability 始终 false。

在有效作者会话且当前学习策略允许时，打开“创作”的“本地控制会话”，按以下顺序操作：

1. 点击“读取本地会话记录”，读取当前身份及本机原命令。打开页面和读取记录不会重发写操作。
2. 点击“准备本地控制会话”，再点击该准备的“读取准备当前状态”。核对冻结范围、固定版本、操作 SHA 和有效期。
3. 明确选择“仅批准这一次本地建会话”或“拒绝这次本地建会话”。拒绝不会创建会话；批准也不立即启动，须另读当前资格。
4. 批准且资格仍 current 时，点击“明确创建这次本地会话”。只有固定受限上游响应核验并保存后才返回原 201 ACK；另读当前准备和会话确认实际状态。

ready 表示曾核验成功的映射，不证明账号登录、模型调用或进程仍在运行。failed 或 unknown 保存实际事实；原命令回放不能第二次启动。consumed/closed 准备仍保留 session ID，可受权查看原实例。若要另建准备，须作为新操作重新核资格和批准；旧未知结果不会被清除。

刷新或同数据库 API 重启后，先读取当前身份及本机原命令，再由原有效作者明确回放原 key/body。原成功 ACK 与当前 GET 分别展示；新会话不能继承旧作者命令。失权或学习策略锁定时禁止写入和回放，安全元数据读取按其合同仍可用。cookie、CSRF、密钥不存入浏览器命令记录。

本机 runtime 只接受固定 Linux x86_64 Codex CLI 0.160.0 字节以及可核验的受限启动闭包。不可用、配置变化或坏历史都会安全拒绝；不会借全局 CLI 登录或降低隔离继续。准备和当前读回不启动 CLI 来消除未知。实际开始许可持久化后保守消费，重启恢复不重复 thread/start。

实际验收见 [本地会话验收记录](../progress/M6.3-bootstrap-acceptance.md)。真实控制、浏览器回归、物理数值环境和完整阶段状态分别记录。当前 M6.3 / AC-21 未完成；turn、通用审批、产物、登录、任务导出与回导须继续按唯一规范逐项实施。
